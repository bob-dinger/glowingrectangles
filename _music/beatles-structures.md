# Beatles Song Structures

## Format
- 8 chars = 1 bar (4 beats)
- 2 chars = 1 beat
- Chord name + dashes = duration
- `|` = bar line
- Pattern letters show phrase repetition (A = first phrase, B = second unique phrase, etc.)
