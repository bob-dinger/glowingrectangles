How it works

1. Write powers of 2: 1, 2, 4, 8, 16...
2. Double the second number alongside
3. Find which powers sum to first number
4. Add corresponding doubled values

Binary connection

13 = 8 + 4 + 1
13 = 1101 in binary

The "used" rows are exactly the 1s in binary!

This is multiplication by shift-and-add—how CPUs do it.

Only need to double

Ancient Egyptians didn't need multiplication tables. Just:

• Double numbers
• Add them up

That's enough to multiply anything!
