Lattice Method

Grid, diagonals, no carrying mistakes

How it works

1. Draw grid (digits across top, digits down side)
2. Draw diagonal in each cell
3. Multiply: tens go top-left, ones go bottom-right
4. Add along each diagonal
5. Read answer around the edge

Why it's great

You never have to hold carries in your head. Each diagonal naturally collects numbers of the same place value.

Hard to make mistakes!
