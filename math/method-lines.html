Line Method

Draw lines. Count intersections. That's it.

How it works

1. Draw lines for first number (diagonal ↘)
2. Draw lines for second number (diagonal ↗)
3. Count intersections in each zone
4. Carry if any zone > 9

Why it works

Each intersection is a unit of multiplication. The zones naturally separate into ones, tens, hundreds.

It's the same math as long multiplication—just visual.

Limitation

Gets messy with big digits. Try 99 × 99 and you'll be counting forever!

Best for numbers with small digits (1s, 2s, 3s).
